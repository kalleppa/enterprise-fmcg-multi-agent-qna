# Enterprise FMCG Multi-Agent Q&A

An enterprise-style multi-agent question-answering prototype for an FMCG company.

## Planned Capabilities

- Structured data retrieval
- Unstructured document retrieval
- Internet search
- Python-based analysis
- Hybrid retrieval
- Multi-turn conversations
- SQL safety controls
- Source citations
- Response validation
- Cost and latency tracking
